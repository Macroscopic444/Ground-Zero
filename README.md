# Ground Zero SMP Website

Static GitHub Pages website for Ground Zero SMP.

## Publish on GitHub Pages
1. Upload every file and the `assets` folder to a repository.
2. In GitHub, open **Settings → Pages**.
3. Set the source to the `main` branch and `/ (root)`.
4. Save.

## Live player counter
The site reads the public server status for `15.235.56.88:25587` from mcsrvstat.us and refreshes every 30 seconds. If the external status service is unavailable, the page shows **STATUS UNAVAILABLE** instead of inventing a player count.
